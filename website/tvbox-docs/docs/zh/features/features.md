# 认识TVboxOSC

为 Android 电视与手机设计，加入自己的来源即可开始使用。

## 双装置体验

**电视与手机介面**

电视用遥控器、手机用触控，支援直向、横向与大萤幕。

## 浏览与搜寻

**分类 · 筛选 · 并行搜寻**

依分类与条件找内容，也能跨站点同时搜寻。

## 播放控制

**倍速 · 比例 · 画中画 · 背景音讯**

切换硬解与软解、调整倍速与比例，支援画中画、背景音讯、[片段跳过](/spider/skips)与下一集预载。

## 字幕与弹幕

**SRT · SSA · ASS · 即时弹幕**

载入外挂字幕、调整字幕样式，支援[即时弹幕](/spider/live-danmaku)与区域网络推送。

## 直播体验

**M3U · TXT · JSON · EPG**

分组选台、查看节目表、收藏频道与切换线路；依来源支援[节目回看](/config/common#节目回看-catchup)与[时间轴拖曳](/spider/timeshift)。

## 个人记录

**观看记录 · 收藏 · 无痕**

保存播放进度与收藏，随时接着看，也可开启无痕模式。

## 跨萤幕投放

**DLNA 投放与接收**

手机可投放到区域网络装置，电视也能接收 DLNA 播放。

## Android Auto

**记录 · 收藏 · 直播 · 搜寻**

在车机浏览记录、收藏与直播分组，搜寻点播或频道并控制播放。

## 远端控制

**网页播放 · 独立遥控器**

用浏览器搜寻、推送网址与控制播放，也能操作遥控器、汇出日志及同步记录。详见[本地 API](/local/remote)。

## 档案与传输

**续传 · 重新命名 · 搬移**

从网页管理装置档案，支援上传续传、重新命名与搬移，也能让 App 下载档案。详见[档案管理](/local/files)与[续传与装置下载](/local/transfers)。

## 爬虫测试

**编辑 · 格式化 · 重测**

载入 Java JAR，或在网页编辑 Python／QuickJS，执行测试并查看结果与网络纪录。详见[测试爬虫](/spider/testing)。

## 扩充模组

**Python · QuickJS · Node.js · mpv**

在 App 安装、更新或移除所需模组，另支援 Thunder 与 BD-J。详见[安装执行模组](/spider/modules)。

## 网络工具箱

**DoH · Proxy · Hosts · Rules**

用配置管理 DNS、代理、Hosts、请求标头与网页撷取规则。详见[共用物件](/config/common)。

---

## 自订播放控制

常用操作，一键执行。用指令按钮调整倍速、音量、延迟与影片缩放。详见[播放指令](/commands/start)。

## 开始使用

第一次使用，从配置开始。加入点播或直播配置，载入自己的站点与频道。详见[配置字典](/config/examples)。
