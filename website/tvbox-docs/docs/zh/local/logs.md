# 日志下载与分享

开启 `/logs.html` 查看日志，自动撷取最长 60 分钟。「停止撷取」停止来源装置的收集；「暂停显示」只暂停画面更新。

「下载日志」与「分享日志」汇出同一份日志档案，包含版本、装置、播放摘要、诊断资料与原始日志。浏览器不支援档案分享时改为下载，可从下载项目再分享；读取资讯失败可按「重新读取资讯」，保留日志。

汇出不受搜寻与等级筛选影响，上限 512 KiB；超限保留较新日志并标示缺漏。档案包含汇出时间、状态取样时间与日志笔数。

手机版的装置清单提供「操作」与「日志」按钮，长按装置名称可命名。别名只存于目前手机，依有效装置识别码保留，不受 IP 改变影响；清空即恢复原名。

## 日志资讯 API

```sh
curl "http://127.0.0.1:9978/log/info"
```

| 栏位 | 用途 |
| --- | --- |
| `version` / `versionCode` / `variant` / `buildType` | 应用版本与建置资讯。 |
| `device` / `android` / `sdk` / `abis` | 装置与 Android 资讯。 |
| `playback` | 播放状态，不含 `artwork`。 |
| `playback.url` | 解析后的完整网址，保留 query；无来源为空字串。 |
| `collection` | 日志收集状态，含 READ_LOGS 权限、目前 UID／PID 等诊断资讯。 |
| `playbackLog` | 目前播放的诊断取样；无播放器时仍依实际状态回传。 |
| `lastPlaybackError` | 最近一次保存的播放错误，没有错误时可为 `null`。 |

GET 回传 JSON；停止或失败后仍保留来源时，网址也会保留。不含封面 URL、UUID、序号或 MAC。

:::warning
日志可能含完整播放网址与查询参数。分享前请自行检查，避免带出签名或授权资讯。
:::
