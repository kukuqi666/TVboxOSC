# 介绍

影視TV 是一款 Android 电视与手机播放器。App 本身不内建或提供任何内容来源，你加入点播或直播配置后，才会载入自己的站点与频道。

爬虫取得资料，App 负责呈现。爬虫依 Result 格式回传分类、列表与播放资讯，因此 Java、Python 与 QuickJS 三种语言共用同一份资料格式。

## 装置

- **Android TV**：以遥控器操作，支援大萤幕与节目表。
- **Android 手机**：以触控操作，支援直向、横向与画中画。

1. [快速开始](/guide/start/getting-started)：加入第一份配置，确认可以播放。
2. [爬虫介接](/spider/load)：需要自己的来源时，从三语言 Demo 开始改。
3. [配置字典](/config/examples)：站点、解析、直播与共用物件的完整栏位。

## 回报问题前

先确认三件事：配置能载入、爬虫测试页的回传有效、App 内能实际播放。模组测试通过或 URL 正确，都不代表播放一定成功。
