# Meet TVboxOSC

Designed for Android TV and phones. Add your own sources and start watching.

## Two-device experience

**TV and phone interfaces**

Remote control on TV, touch on phones; portrait, landscape and large screens are supported.

## Browse and search

**Categories · Filters · Parallel search**

Find content by category and filters, or search several sites at once.

## Playback control

**Speed · Aspect · PiP · Background audio**

Switch hardware and software decoding, adjust speed and aspect, and use picture-in-picture, background audio, [skip segments](/spider/skips) and next-episode preloading.

## Subtitles and danmaku

**SRT · SSA · ASS · Live danmaku**

Load external subtitles, adjust subtitle styles, and use [live danmaku](/spider/live-danmaku) with LAN push.

## Live TV

**M3U · TXT · JSON · EPG**

Switch channels by group, view EPG, favorite channels and switch lines; [catch-up](/config/common#节目回看-catchup) and a [draggable timeline](/spider/timeshift) are available depending on the source.

## Personal records

**History · Favorites · Incognito**

Save playback progress and favorites, resume anytime, or use incognito mode.

## Cast between screens

**DLNA send and receive**

Cast from a phone to LAN devices, and receive DLNA playback on a TV.

## Android Auto

**History · Favorites · Live · Search**

Browse history, favorites and live groups on the car head unit, search VOD or channels, and control playback.

## Remote control

**Web player · Standalone remote**

Search, push URLs and control playback from a browser, plus remote keys, log export and record sync. See the [local API](/local/remote).

## Files and transfers

**Resume · Rename · Move**

Manage device files from the browser, with resumable upload, rename and move, and let the App download files. See [file management](/local/files) and [resumable transfers](/local/transfers).

## Spider testing

**Edit · Format · Retest**

Load a Java JAR, or edit Python／QuickJS in the browser, then run tests and inspect results and network logs. See [testing a spider](/spider/testing).

## Runtime modules

**Python · QuickJS · Node.js · mpv**

Install, update or remove the modules you need, plus Thunder and BD-J. See [runtime modules](/spider/modules).

## Network toolbox

**DoH · Proxy · Hosts · Rules**

Manage DNS, proxies, hosts, request headers and WebView capture rules from configuration. See [shared objects](/config/common).

---

## Custom playback controls

Common actions in one tap. Use command buttons to adjust speed, volume, delay and video scaling. See [playback commands](/commands/start).

## Getting started

Your first session starts with configuration. Add a VOD or live TV configuration to load your own sites and channels. See the [configuration reference](/config/examples).
